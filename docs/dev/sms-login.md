# 用户可控短信验证码登录（实验性）

关联 #606。设置 → 短信验证码登录中默认关闭；用户先阅读说明，再请求 Android `RECEIVE_SMS` 权限。只有权限获准后才保存开启状态；拒绝、权限撤销、损坏的设置或保存失败均保留手工登录。关闭会使当前授权版本失效，取消正在等待的授权页和短信监听；再次开启不会恢复旧任务的授权。已交给 Android 的一次输入不能撤回。

## 当前支持的流程

1. 用户明确要求登录对应 App，且从本机 UI 发起主任务。Mika 打开登录页、填写账户，找出原生验证码输入框和“获取/发送/重新发送验证码”按钮的完整资源 ID。不要提前请求短信。
2. `phone_sms_login(app, resourceId, sendButtonId)` 先核对应用访问许可和当前页面，再打开本机授权浮层。用户确认目标 App 名称及包名，依据已知短信自行填写准确发送方、括号内的服务签名，以及登录页和短信中均作为独立数字出现的 4–11 位账户数字。不要求在聊天中提供号码、短信或验证码。这些匹配参数仅留在内存，不进入模型参数、AskPort、对话、记忆或磁盘。
3. 用户仅授权本次后，注册临时 `SMS_RECEIVED` 接收器，再点击已验证的原生发送按钮一次。接收器要求系统签名级 `BROADCAST_SMS` 发送权限，处理同一发送方的短信分段，拒绝授权前的短信（发送时间按短信的一秒精度比较）、超时短信和明显的未来时间。最长监听 90 秒，整个流程最长 180 秒。不读取收件箱，不注册常驻接收器，也不要求默认短信应用身份。
4. 本机要求发送方完全一致、正文开头为 `【服务签名】` 或 `[服务签名]`、含“登录”、含对应账户数字，且只有一个明确标记的 4–8 位数字验证码。付款、转账、银行、注册、改密、找回、绑定等消息和歧义内容拒绝。一次窗口最多消费一条匹配短信。
5. 输入前再次检查当前 App、主用户资料、账户、唯一原生验证码框和权限版本。仅对准确控件调用 `ACTION_SET_TEXT` 一次，不使用焦点兜底、坐标、剪贴板、shell、重试或通用 `phone_type_text`。`filled` 只表示控件接受了输入，不能声称已经登录。
6. 为防填写后的页面再次泄露验证码，从授权浮层打开起，本任务的后续手机读屏、OCR、截图、通知事件及预览持续隐藏，普通控件操作被拒绝。需要额外提交或验证时交用户接管并结束任务；不会自动点击“登录”、同意协议、付款或风险验证。部分 App 在填入后会自行完成登录。

## 隐私与撤销

`SmsLoginPort` 只返回枚举状态，没有返回短信或验证码的接口。可变验证码数组在成功、失败、取消和超时竞争中清零；Android 框架和 `ACTION_SET_TEXT` 必需的临时不可变字符串无法保证原地清零，不会主动写入日志或长期存储。授权页面使用 `FLAG_SECURE`，并复用现有敏感设置界面门禁。目标 App 的教学事件及私密流程期间的无障碍通知事件不复制给录制/观察订阅者。主动通知收件箱在入库前拒绝含认证秘密的通知，保留原来的白名单和应用访问检查。

开关的撤销与最后一次系统输入共用锁：关闭返回后不能再开始旧授权的系统输入。取消、超时、任务停止或系统异常会关闭浮层、注销接收器、清除暂存的代码；流程不跨进程恢复。任何无法可靠确认的情况都返回状态，由用户手工接管。

## 能力边界和待验证事项

- Android 10+ 宿主；仅本机 UI 主任务，拒绝无人值守、子任务、渠道、MCP 和条件检查。具体手机操作仍需要 Mika 现有助手及无障碍能力。
- `RECEIVE_SMS` 是 Android 的危险且受严格限制的权限，安装器白名单、厂商 ROM 和分发渠道政策可能阻止授予。不会通过 shell 提权、切换默认短信角色或绕过安装器限制。详见 [Android 权限文档](https://developer.android.com/reference/android/Manifest.permission#RECEIVE_SMS)。设备无短信能力时继续手工处理。
- 只覆盖上述中文短信格式。许多短信没有账户标识，或页面只有完整号码而短信只有尾号，无法严格匹配时必须手工操作；用户不得把任意数字当成账户标识。
- 不支持网页/WebView、分格验证码框、没有资源 ID 的界面、其他 Android 用户/工作资料/分身、验证码不一致的账户、支付/身份核验、旧短信、自动点登录及完整的无人工登录流程。
- 标准手机工具的隐私屏障覆盖本次运行。沙箱任意命令、外部 MCP、其他应用和系统自身的短信存储不是本功能的隔离对象；这不构成抵抗任意同 UID 代码的安全沙箱。提示词禁止通过这些路径绕过拒绝。新的独立任务或用户主动分享仍沿用原有读屏能力，不能把本功能当成全局数据防泄漏机制。
- 自动测试覆盖本机匹配规则、窗口时效/单次消费、工具状态接口、读屏屏障、设置默认值、损坏/写入失败和撤销同步。仍需使用合成短信在真机/测试 SIM 上验证：安装器受限权限、各 ROM 的广播、分段短信、授权浮层输入、无障碍原生控件和完整取消/权限撤销时序。未进行任何真实验证码或真实账户登录测试。

实现分层：`core/cap/phone/sms/` 保存匹配和短期窗口状态；`PhoneSmsLogin` 仅声明专用工具；`app/cap/phone/sms/` 处理 Android 权限、授权 UI 和广播；`AndroidScreen` 保留准确控件校验及本机输入；`TaskRun` 只为本机主任务装配端口，并在任务收尾释放隐私事件保护。
